# Credential-free routing rules

This repository contains rules, the single policy source and generators only. No proxy node credentials are stored here.

Shadowrocket: import `Unified-Shadowrocket.conf` as a remote configuration, retain your existing nodes and select Config routing mode.

Upstream data: https://github.com/MetaCubeX/meta-rules-dat ; applicable upstream data licenses and attribution remain with their authors.

Edit policy.json to change custom domains. GitHub Actions rebuilds artifacts on source updates and daily. Rule-only endpoints are public. Do not add private internal domains or node credentials.

macOS process rules cannot identify iOS apps; media playback must be checked separately.
